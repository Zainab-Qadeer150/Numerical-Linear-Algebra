# Numerical Linear Algebra

A collection of numerical linear algebra algorithms implemented in Python, focusing on the computational solution of linear systems, matrix computations, iterative methods, numerical accuracy, and convergence analysis.

## Topics Covered

### Direct Methods
- Gaussian Elimination
- LU Decomposition

### Iterative Methods
- Jacobi Iterative Method
- Gauss-Seidel Method

### Numerical Analysis
- Residual Error Analysis
- Convergence Analysis
- Numerical Stability
- Computational Efficiency

## Tools

- Python
- NumPy
- Matplotlib

## Objectives

This repository demonstrates the implementation and analysis of fundamental numerical linear algebra techniques used to solve mathematical and engineering problems computationally.

Each method includes:
- Mathematical formulation
- Numerical algorithm
- Python implementation
- Numerical results
- Error analysis
- Convergence analysis where applicable

## Applications

Numerical linear algebra provides the computational foundation for many scientific and engineering applications, including:

- Engineering simulations
- Scientific computing
- Partial differential equations
- Finite Element Methods
- Optimization
- Data and computational modeling
