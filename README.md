# Numerical Linear Algebra

A computational study of fundamental **numerical linear algebra methods implemented in Python** for solving linear systems and performing matrix-based computations. The repository focuses on the mathematical formulation, algorithmic implementation, numerical accuracy, convergence behavior, stability, and computational efficiency of direct and iterative solution techniques.

## Overview

Numerical linear algebra provides the computational foundation for scientific computing, numerical PDEs, finite element methods, optimization, and mathematical modeling. Many computational problems ultimately lead to systems of linear algebraic equations that must be solved efficiently and reliably.

This repository develops these techniques from their mathematical foundations to practical Python implementations, with emphasis on understanding **how numerical algorithms work and how their solutions can be evaluated and validated**.

## Topics Covered

### Direct Methods

Methods that obtain solutions through systematic matrix transformations:

* **Gaussian Elimination**
* **LU Decomposition**

These implementations demonstrate matrix factorization, elimination procedures, solution of linear systems, and numerical considerations associated with direct methods.

### Iterative Methods

Methods that progressively approximate the solution through successive iterations:

* **Jacobi Iterative Method**
* **Gauss-Seidel Method**

The implementations investigate iterative convergence, stopping criteria, residual behavior, and conditions that influence convergence.

## Numerical Analysis

The computational experiments emphasize:

* Numerical approximation
* Residual error analysis
* Convergence analysis
* Numerical stability
* Iterative convergence
* Tolerance and stopping criteria
* Computational efficiency
* Matrix conditioning and solution reliability

Where appropriate, numerical solutions are evaluated using residuals and convergence behavior to assess the reliability of the computed results.

## Computational Workflow

The implementations follow a systematic numerical workflow:

**Mathematical Formulation → Algorithm → Python Implementation → Numerical Solution → Residual/Error Analysis → Convergence Assessment → Computational Evaluation**

This approach shows that solving a linear system computationally involves not only obtaining a solution,but also determining whether the solution is **accurate, stable, and numerically reliable**.

## Tools and Technologies

* **Python** — primary programming language
* **NumPy** — arrays, matrix operations, and numerical linear algebra
* **Matplotlib** — visualization of convergence, residuals, and numerical results
* **Jupyter Notebook / Google Collab** — interactive computational experiments

## Objectives

The main objectives of this repository are to:

* Implement fundamental numerical linear algebra algorithms from their mathematical formulations.
* Develop practical understanding of direct and iterative solution methods.
* Analyze numerical accuracy and residual errors.
* Investigate convergence behavior of iterative algorithms.
* Examine numerical stability and computational efficiency.
* Build a foundation for more advanced numerical methods and scientific computing.

Each implementation includes, where applicable:

* Mathematical formulation
* Numerical algorithm
* Python implementation
* Numerical experiments
* Numerical results
* Residual/error analysis
* Convergence analysis

## Applications

Numerical linear algebra techniques form the computational foundation of many areas of mathematics, science, and engineering, including:

* Scientific computing
* Engineering simulations
* Partial differential equations
* Finite Element Methods
* Optimization
* Mathematical modeling
* Computational physics
* Data and computational science

In particular, the linear systems arising from **finite difference and finite element discretizations of PDEs** can be solved using many of the techniques explored in this repository.


## Key Outcomes

This repository demonstrates the progression from **mathematical linear systems to reliable computational solutions**, combining numerical linear algebra theory with scientific programming and numerical validation.

The work provides an essential computational foundation for subsequent studies in **numerical PDEs, finite element methods, nonlinear systems, and advanced computational mathematics**.
